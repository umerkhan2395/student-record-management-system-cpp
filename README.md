📘 Student Management System (C++)
📌 Project Description

This is a menu-driven Student Management System written in C++.
The program allows users to manage student records using basic operations such as add, display, search, and delete.
Student data is stored temporarily in memory using a vector of structures.

🎯 Features

Add a new student record

Display all student records

Search a student by roll number

Delete a student by roll number

User-friendly menu system

🛠 Technologies Used

Language: C++

Concepts Used:

Structures

Vectors (dynamic arrays)

Functions

Loops

Conditional statements

Switch-case

🧾 Student Data Fields

Each student record contains:

Name

Roll Number

Branch

Course

Email ID

⚙️ How the Program Works

The program displays a menu.

The user selects an option (1–5).

Based on the choice:

Student data is added, displayed, searched, or deleted.

The program runs continuously until the user chooses Exit.

▶️ How to Run the Program

Open any C++ compiler (Dev-C++, Code::Blocks, VS Code, etc.).

Copy the source code into a .cpp file.

Compile and run the program.

Follow on-screen instructions.
